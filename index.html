Introdução e Objetivo Geral

Este diário de bordo documenta a jornada de investigação prática e teórica em Robótica, Física e Tecnociência, explorando a criação de protótipos interativos e soluções baseadas em tecnologia.

Tecnologia, IA e a Visão Humana

Como a ciência, a tecnologia e a inteligência artificial podem contribuir para a melhoria da visão humana e para a acessibilidade visual?

A interseção entre física óptica, eletrônica e IA permite a criação de próteses visuais (como retinas artificiais), sistemas de computação gráfica voltados à ampliação adaptativa de contraste em tempo real e algoritmos de visão computacional capazes de descrever o ambiente e textos para pessoas com deficiência visual severa ou cegueira.

Projetos Desenvolvidos

1. Disco de Newton

Objetivo: Demonstrar a decomposição e a síntese da luz branca através da rotação de cores primárias e secundárias.

Componentes Utilizados:

  • Motor DC 3V-6V
  • Disco impresso com o espectro visível
  • Bateria 9V e suporte
  • Interruptor simples

Erros e Soluções:

Erro: O disco trepidava excessivamente e a mistura de cores não ficava homogênea.

Solução: Rebalanceamos o centro de massa do disco de papelão rígido e fixamos o eixo do motor com silicone denso.

Código / Esquemático:

// Circuito puramente elétrico acionado por interruptor físico.
// Tensão: 5V DC | Corrente nominal: 150mA

Ideia de Protótipo Acessível:

Adição de um sensor de velocidade (encoder) acoplado a um buzzer que emite um tom sonoro contínuo cuja frequência varia conforme a velocidade de rotação, permitindo que estudantes cego(a)s percebam auditivamente a aceleração do disco.

2. LED Fade-in / Fade-out

Objetivo: Controlar a intensidade luminosa de um LED gradualmente utilizando sinal PWM (Pulse Width Modulation).

Componentes Utilizados:

  • Placa Arduino Uno
  • 1 LED Difuso 5mm
  • 1 Resistor 220Ω
  • Protoboard e Jumpers

Erros e Soluções:

Erro: O LED ligava e desligava abruptamente em vez de variar suavemente.

Solução: O pino de saída foi alterado de um pino digital comum para um pino compatível com PWM (pino 9 com o símbolo ~).

Código Arduino (C++):

int led = 9;
void setup() {
  pinMode(led, OUTPUT);
}
void loop() {
  for (int i = 0; i <= 255; i += 5) {
    analogWrite(led, i);
    delay(30);
  }
  for (int i = 255; i >= 0; i -= 5) {
    analogWrite(led, i);
    delay(30);
  }
}

Ideia de Protótipo Acessível:

Sincronização do sinal PWM com um vibrador de celular (micro motor de tique haptic), permitindo que pessoas com deficiência visual e auditiva sintam a gradação da potência através da intensidade do estímulo tátil.

3. LED RGB

Objetivo: Misturar as três cores primárias da luz (Vermelho, Verde e Azul) para sintetizar cores secundárias e terciárias.

Componentes Utilizados:

  • 1 LED RGB Anodo Comum
  • 3 Resistores 220Ω
  • 3 Potenciômetros de 10kΩ
  • Placa Arduino Uno

Erros e Soluções:

Erro: As cores geradas ficavam distorcidas e o componente esquentava.

Solução: O pino comum do LED havia sido ligado ao GND em vez de 5V (pois era de anodo comum). Corrigimos o barramento elétrico.

Código Arduino (C++):

const int pR = 9, pG = 10, pB = 11;
void setup() {
  pinMode(pR, OUTPUT);
  pinMode(pG, OUTPUT);
  pinMode(pB, OUTPUT);
}
void loop() {
  // Exemplo de cor Magenta (R + B)
  analogWrite(pR, 0);   // Anodo Comum: 0 ativa
  analogWrite(pG, 255); // 255 desativa
  analogWrite(pB, 0);
}

Ideia de Protótipo Acessível:

Associação de cada cor primária (R, G, B) a uma frequência de áudio única. Ao misturar as cores no LED, o circuito reproduz um acorde musical correspondente à cor combinada.

4. Arco-íris com LED Endereçável

Objetivo: Mapear e transicionar sequencialmente todo o espectro visível em uma fita de LEDs endereçáveis.

Componentes Utilizados:

  • Módulo de LED Endereçável WS2812B
  • 1 Capacímetro / Resistor de proteção 470Ω
  • Fonte externa 5V 2A
  • Placa Arduino Uno

Erros e Soluções:

Erro: Os últimos LEDs da fita apresentavam oscilação de cor e tom avermelhado.

Solução: A corrente fornecida pela porta USB do Arduino era insuficiente. Adicionamos uma fonte externa dedicada de 5V compartilhando o GND.

Código Arduino (C++):

#include <Adafruit_NeoPixel.h>
#define PIN 6
#define NUMPIXELS 8
Adafruit_NeoPixel strip(NUMPIXELS, PIN, NEO_GRB + NEO_KHZ800);

void setup() {
  strip.begin();
  strip.show();
}

Ideia de Protótipo Acessível:

Construção de uma maquete tátil em relevo onde a posição do LED no gradiente corresponde a diferentes texturas físicas (de áspero a liso), associadas aos comprimentos de onda do espectro visível.

5. Semáforo para Cruzamento

Objetivo: Modelar o controle temporal de tráfego de um cruzamento rodoviário e pedestres priorizando a segurança transitória.

Componentes Utilizados:

  • 6 LEDs (2 Vermelhos, 2 Amarelos, 2 Verdes)
  • 6 Resistores 220Ω
  • 1 Buzzer Passivo
  • Placa Arduino Uno

Erros e Soluções:

Erro: Ambos os semáforos ficavam verdes ao mesmo tempo, gerando simulação de colisão.

Solução: Reescrevemos a matriz de tempos do código utilizando variáveis claras de estado para garantir a intertrava do cruzamento.

Código Arduino (C++):

// Trecho de alternância do semáforo
digitalWrite(vA, HIGH); 
digitalWrite(vmB, HIGH);
delay(5000);
digitalWrite(vA, LOW);
digitalWrite(amA, HIGH);
delay(2000);

Ideia de Protótipo Acessível:

Implementação de aviso sonoro com cadência variável para travessia de pedestres cego(a)s (bipes rápidos para 'Siga' e lentos para 'Atenção') integrado a piso tátil na maquete.

6. Sensor de Movimento (PIR / Ultrassônico)

Objetivo: Detectar presença ou variação de distância no ambiente e acionar alertas visuais e sonoros.

Componentes Utilizados:

  • Sensor Ultrassônico HC-SR04 ou PIR
  • 1 Buzzer Ativo
  • 1 LED Indicador
  • Placa Arduino Uno

Erros e Soluções:

Erro: O sensor retornava distâncias nulas ou leituras falsas constantes.

Solução: Adicionamos um filtro de média móvel no código para ignorar ruídos e picos de leitura fora do alcance físico do sensor.

Código Arduino (C++):

long duracao;
int distancia;
digitalWrite(trigPin, LOW);
delayMicroseconds(2);
digitalWrite(trigPin, HIGH);
delayMicroseconds(10);
duracao = pulseIn(echoPin, HIGH);
distancia = duracao * 0.034 / 2;

Ideia de Protótipo Acessível:

Desenvolvimento de um dispositivo vestível de auxílio à mobilidade (como uma bengala longa inteligente) que emite feedback tátil através de motor de vibração proporcional à proximidade de obstáculos aéreos ou frontais.
